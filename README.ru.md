# Chaos Heart: локализация Morrowind с русского на английский

Портфолио Антона Гавриленко: инженерная и редакторская сторона локализации Russian 1C Morrowind + Chaos Heart для OpenMW.

Задача — сохранить игровую логику русской версии, использовать официальный английский текст там, где он уже существует, и перевести новый материал мода. Отдельная работа — речевой стиль Камонна Тонг: сочетание криминальных регистров Baltimore / The Wire и Birmingham / Peaky Blinders с грубоватой речью бандитов Kingdom Come, без прямых цитат и выхода из мира Morrowind.

## Что показано

- Извлечение и сопоставление записей ESM/ESP, повторное использование официальной локализации.
- Локальный GPU-инференс через ollama; ограничения VRAM, параллельная обработка и борьба со свопом.
- Возобновляемая обработка через JSONL и systemd, защита редакторских исправлений от перезаписи.
- Проверка терминов, переменных, кодировки и точных названий диалоговых тем.
- Масштабная вычитка и исправление конкретного бага, где удачный по смыслу перевод блокировал продолжение квеста.
- Честное описание текущего состояния: рабочая локальная сборка есть, итоговый публичный пакет не завершён.

Моя роль — постановка задачи, художественное направление, правила терминологии, оценка качества, организация проверки и игровая итерация. Claude Code помогал с кодом, переводом, редактурой и отладкой; Gemma использовалась для чернового массового перевода.
